# lifeos

Пакет AUR для [Life OS](https://github.com/Konor11/life-os) — нативного клиента панели
управления ИИ-агентами (Tauri v2).

Интерфейс в пакет **не входит**: приложение загружает панель с `https://lifeos.dktunnel.xyz`.
Поэтому пакет маленький, а панель всегда свежая — обновления приезжают сами.

## Что внутри пакета

- `/usr/bin/lifeos` — приложение (~6 МБ);
- ярлык в `/usr/share/applications/`;
- иконки 32/128/512 в `/usr/share/icons/hicolor/`.

## Установка

```bash
yay -S lifeos      # или paru -S lifeos
```

Сборка из исходников занимает 10–25 минут: компилируется около 400 Rust-крейтов. Готовый
AppImage, если не хочется ждать, лежит в разделе Releases:
https://github.com/Konor11/life-os/releases

## Запуск и вход

После первого запуска войди в панель — логин и пароль те же, что на сервере.

- крестик сворачивает приложение в трей, а не закрывает;
- `Ctrl+Alt+Space` — показать или спрятать окно из любого места;
- уведомления панели приходят системными;
- автозапуск включается в Настройках → Система.

## Для сопровождающих

Исходники пакета лежат в `desktop/` основного репозитория. После правок:

1. поднять версию в `desktop/src-tauri/tauri.conf.json` и в этом `PKGBUILD`;
2. пересобрать архив `lifeos-desktop-<верс>.tar.gz` из каталога `desktop/`;
3. создать релиз с этим архивом (PKGBUILD ссылается на релиз, а не на авто-архив тега —
   релизный файл неизменяемый, и хеш не «поедет» задним числом);
4. обновить `sha256sums`;
5. перегенерировать `.SRCINFO`:

```bash
cd aur
makepkg --printsrcinfo > .SRCINFO
```

и запушить в `aur.archlinux.org/lifeos.git`.
